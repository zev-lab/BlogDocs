JavaScript 面向对象编程与原型链

JavaScript 是一门基于原型 (Prototype) 的面向对象语言。虽然 ES6 引入了 class 关键字，但其底层依然是通过原型链来实现的。理解原型和继承，是彻底掌握 JavaScript 的必经之路。

1. 面向对象概述

面向对象（OOP）编程关注的是**参与者（对象）**应该具备怎样的行为与特征。 它的三大核心特点是：

  • 封装：将属性和行为封装在对象内部，对外隐藏实现细节。
  • 继承：子类可以继承父类的特征和行为，提高代码复用性。
  • 多态：不同对象对同一行为作出不同的响应。

JS 中创建对象的几种方式

  1. 字面量创建
let obj = {
    name: '张三',
    say: function() { console.log('你好'); }
};
  1. 工厂模式 利用普通函数封装创建对象的逻辑：
function createStudent(name, age) {
    return { name, age };
}
let s1 = createStudent('李四', 20);
  1. 构造函数模式 构造函数本质上也是普通函数，但约定首字母大写，并且必须通过 new 关键字来调用。
function Person(name, age) {
    this.name = name;
    this.age = age;
    this.eat = function() {
        console.log('吃饭');
    }
}
let p1 = new Person('王五', 25);

new 关键字背后的四个步骤：

  1. 在内存中创建一个全新的空对象。
  2. 将这个新对象的内部 [[Prototype]]（即 __proto__）链接到构造函数的 prototype 对象。
  3. 将构造函数内部的 this 绑定到这个新对象上，并执行构造函数内部的代码（为新对象添加属性）。
  4. 如果构造函数没有返回非空对象，则返回这个新对象。

2. 原型 (Prototype)

如果在构造函数内部通过 this.method = function(){} 添加方法，那么每次 new 一个新实例，这个方法都会在内存中被重新创建一份，极大地浪费内存。

解决方法：原型模式。 每个构造函数都有一个 prototype 属性，它指向一个对象（称为原型对象）。这个对象包含着特定类型的所有实例共享的属性和方法。

function Animal(type) {
    this.type = type;
}
// 将共享的方法挂载到原型上
Animal.prototype.eat = function() {
    console.log("动物在进食");
};

let cat = new Animal('猫');
let dog = new Animal('狗');
cat.eat(); // 动物在进食
console.log(cat.eat === dog.eat); // true (它们共享了同一个内存地址的方法)

3. 原型链与继承

对象在访问某个属性或方法时，首先会在自身的本地属性中寻找；如果找不到，就会沿着 __proto__ 指针，去构造函数的原型对象上寻找；如果还找不到，就继续沿着原型的原型向上查找，直到找到 Object.prototype，再往上就是 null。这条链路就是原型链。

利用原型链，我们可以实现 JavaScript 中的继承。

3.1 构造函数继承 (伪继承)

利用 call() 或 apply() 在子类构造函数中调用父类构造函数。

  • 优点：可以向父类传参，且避免了引用类型的属性被所有实例共享。
  • 缺点：只能继承父类的实例属性，无法继承父类原型 (prototype) 上的方法。
function Parent(name) {
    this.name = name;
    this.colors = ['red', 'blue'];
}
Parent.prototype.say = function() { console.log(this.name); }

function Child(name, age) {
    // 继承了 Parent 的实例属性
    Parent.call(this, name); 
    this.age = age;
}
let c1 = new Child('Tom', 10);
// c1.say(); // 报错：c1.say is not a function

3.2 组合继承 (经典继承)

将构造函数继承和原型链继承组合起来。

  • 优点：既能继承实例属性，又能继承原型方法。
  • 缺点：父类构造函数会被调用两次（一次在 call，一次在 new Parent()），子类的原型上会多出一份多余的父类实例属性。
function Child(name, age) {
    Parent.call(this, name); // 第二次调用
}
Child.prototype = new Parent(); // 第一次调用
Child.prototype.constructor = Child; // 修复 constructor 指向

3.3 寄生组合式继承 (完美方案)

这是在 ES5 中实现继承的最佳方式，它通过 Object.create() 创建一个父类原型的副本，从而避免了调用父类构造函数。

function Parent(name) {
    this.name = name;
}
Parent.prototype.say = function() { console.log(this.name); }

function Child(name, age) {
    Parent.call(this, name); // 继承属性
    this.age = age;
}

// 继承原型方法，不调用父类构造函数
Child.prototype = Object.create(Parent.prototype);
// 修复 constructor
Child.prototype.constructor = Child;

let c1 = new Child('Jerry', 5);
c1.say(); // 正常输出 Jerry

4. 总结

在现代 ES6 开发中，我们通常直接使用 class 和 extends 关键字来实现面向对象和继承，这使得代码更加清晰易懂。但 class 仅仅是语法糖，其底层原理依然是上述的构造函数与寄生组合式原型链继承。深入理解原型链，是解决 JS 疑难杂症的核心钥匙。
