JavaScript 基础：正则表达式与表单验证

正则表达式（Regular Expression，简称 RegExp）是用于匹配字符串中字符组合的模式。在 JavaScript 中，正则表达式不仅可以用来快速检索和替换文本，更是我们在前端实现表单格式验证（如手机号、邮箱、密码强度）的利器。

1. 正则表达式基础

在 JS 中，通常使用一对双斜杠 // 来定义一个正则表达式（字面量形式）。

// 定义一个匹配小写字母 a 的正则表达式
let reg = /a/;

正则表达式通过元字符（具有特殊含义的符号）来制定规则：

1.1 常用元字符

  • .：匹配除换行符以外的任意一个字符。
  • \d：匹配任意一个数字，等价于 [0-9]。
  • \D：匹配任意一个非数字字符。
  • \w：匹配任意一个字母、数字或下划线，等价于 [A-Za-z0-9_]。
  • \W：匹配非字母数字下划线的字符。
  • \s：匹配任意空白字符（空格、制表符等）。

1.2 边界符

  • ^：匹配字符串的开始位置。
  • $：匹配字符串的结束位置。

提示：如果正则表达式以 ^ 开头，以 $ 结尾，则表示要求精确完全匹配整个字符串，而不能仅仅是包含部分。这在表单验证中非常关键！

1.3 字符类 []

方括号用于匹配内部的任意一个字符。

  • [abc]：匹配 a 或 b 或 c。
  • [a-z]：连字符 - 表示范围，匹配小写字母 a 到 z 间的任意字符。
  • [^abc]：在方括号内部的 ^ 表示取反，匹配不是 a、b、c 的任意字符。

1.4 量词 {}

量词用于设定其前面的字符连续出现的次数。

  • *：重复 0 次或更多次（等价于 {0,}）。
  • +：重复 1 次或更多次（等价于 {1,}）。
  • ?：重复 0 次或 1 次（等价于 {0,1}）。
  • {n}：精确重复 n 次。
  • {n,m}：重复 n 到 m 次。
let reg = /^[a-z]{3,6}$/; // 必须是3到6个纯小写英文字母

2. 正则操作常用方法

2.1 RegExp 的 test() 方法

检测给定的字符串是否符合正则表达式的规则。符合返回 true，否则返回 false。常用于表单验证。

let phoneReg = /^1[3-9]\d{9}$/; 
console.log(phoneReg.test("13812345678")); // true
console.log(phoneReg.test("23812345678")); // false

2.2 String 的 match() 方法

在字符串中查找匹配的内容。如果找到则返回一个数组，找不到返回 null。

2.3 String 的 replace() 方法

使用正则表达式去替换字符串中的指定内容。

注：正则末尾加上修饰符 g（global）表示全局匹配替换；加上 i 表示忽略大小写。

let str = "一个和尚有水吃，两个和尚抬水吃";
let reg = /[和尚]|水/g; // 匹配'和'或'尚'或'水'，全局查找
let result = str.replace(reg, '*'); 
console.log(result); // "一个**有*吃，两个**抬*吃" (类似敏感词过滤功能)

3. 常见实战表单验证正则

在注册或登录页面，我们需要对用户的输入进行格式校验。以下是前端开发中最常用的几条正则表达式：

3.1 手机号码验证

规则：11位数字，以1开头，第二位通常为3到9。

let phonePattern = /^1[3-9]\d{9}$/;

3.2 电子邮箱验证

规则：字母/数字/下划线组合 + @ + 字母/数字组合 + . + 后缀。

// 简单实用版
let emailPattern = /^\w+([-+.]\w+)*@\w+([-.]\w+)*\.\w+([-.]\w+)*$/;

3.3 密码强度验证

规则：6 到 16 位，必须包含大小写字母和数字的组合。

// 利用前瞻断言(?=)实现多条件要求
let passwordPattern = /^(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).{6,16}$/;

如果只要求“6-16位的字母数字或下划线”（中低强度）：

let simplePwd = /^\w{6,16}$/;

3.4 纯中文字符验证

规则：利用 Unicode 编码范围，中文的范围为 \u4e00-\u9fa5。

// 名字输入框通常要求必须是纯汉字
let chinesePattern = /^[\u4e00-\u9fa5]+$/;

3.5 身份证号码验证 (简易版)

规则：18位，前17位是数字，最后一位是数字或者大写字母 X。

let idCardPattern = /^\d{17}[\dX]$/;

实战用法示例：

let inputNode = document.querySelector('#emailInput');
let errorMsg = document.querySelector('.error');

inputNode.onblur = function() { // 失去焦点时校验
    let val = this.value;
    if(!emailPattern.test(val)) {
        errorMsg.innerText = "邮箱格式不正确！";
        errorMsg.style.display = "block";
    } else {
        errorMsg.style.display = "none";
    }
}

掌握好正则表达式，不仅能写出严谨的表单验证逻辑，还能在很多文本处理、数据清洗的任务中大幅度节省代码量。
