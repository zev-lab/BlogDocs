JavaScript 基础：数组与常用操作

数组（Array）是 JavaScript 中最常用的数据结构之一。它是一个有序的数据集合，可以用来在一个变量中存储多个不同类型的值。

1. 数组的创建与访问

创建数组

通常推荐使用字面量的方式来创建数组。

// 创建空数组
let emptyArr = [];

// 创建包含多个元素的数组，元素类型可以不同
let mixedArr = [1, "hello", true, null, { name: "Tom" }];

访问和修改数组元素

数组中的每个元素都有一个对应的索引（下标），索引从 0 开始。

let fruits = ["苹果", "香蕉", "橘子"];

// 访问元素
console.log(fruits[0]); // 苹果
console.log(fruits[2]); // 橘子

// 修改元素
fruits[1] = "西瓜";
console.log(fruits); // ["苹果", "西瓜", "橘子"]

// 获取数组长度
console.log(fruits.length); // 3

2. 数组的常用遍历方法

最传统的遍历方式是 for 循环：

let arr = [10, 20, 30];
for (let i = 0; i < arr.length; i++) {
    console.log(arr[i]);
}

现代 JS 中，更推荐使用数组自带的遍历方法，如 forEach 或 for...of：

arr.forEach(function(item, index) {
    console.log(`索引 ${index} 的值是 ${item}`);
});

3. 数组的核心操作方法

JavaScript 提供了丰富的内置方法来增删改查数组元素。

3.1 尾部添加和删除 (push / pop)

  • push(): 在数组末尾添加一个或多个元素，返回数组的新长度。
  • pop(): 删除数组末尾的最后一个元素，返回被删除的元素。
let arr = [1, 2];
arr.push(3, 4); // 返回 4，arr 变为 [1, 2, 3, 4]
let last = arr.pop(); // 返回 4，arr 变为 [1, 2, 3]

3.2 头部添加和删除 (unshift / shift)

  • unshift(): 在数组开头添加一个或多个元素。
  • shift(): 删除数组开头的第一个元素。
let arr = [2, 3];
arr.unshift(1); // arr 变为 [1, 2, 3]
arr.shift();    // arr 变为 [2, 3]

3.3 万能操作方法 (splice)

splice(start, deleteCount, item1, item2, ...) 可以实现数组的删除、插入和替换操作。

  • start: 起始索引。
  • deleteCount: 要删除的元素个数（如果是 0，则不删除元素）。
  • item1, item2: 要插入的新元素。
let arr = ["A", "B", "C", "D"];

// 删除：从索引 1 开始删除 2 个元素
arr.splice(1, 2); // arr 变为 ["A", "D"]

// 插入：从索引 1 处插入元素
arr.splice(1, 0, "X", "Y"); // arr 变为 ["A", "X", "Y", "D"]

// 替换：从索引 1 开始删除 1 个元素，并插入新元素
arr.splice(1, 1, "Z"); // arr 变为 ["A", "Z", "Y", "D"]

3.4 数组截取 (slice)

slice(start, end) 返回一个新的数组对象，包含从 start 到 end（不包括 end）的原数组浅拷贝元素。原数组不会被修改。

let arr = ["A", "B", "C", "D"];
let newArr = arr.slice(1, 3); // ["B", "C"]

3.5 数组拼接 (concat)

concat() 用于合并两个或多个数组。此方法不会更改现有数组，而是返回一个新数组。

let arr1 = [1, 2];
let arr2 = [3, 4];
let result = arr1.concat(arr2); // [1, 2, 3, 4]

3.6 数组转字符串 (join)

join(separator) 方法将一个数组的所有元素连接成一个字符串并返回。

let elements = ['Fire', 'Air', 'Water'];
console.log(elements.join('-')); // "Fire-Air-Water"

4. 多维数组 (二维数组)

当数组里面的元素也是一个数组时，这就构成了二维数组。二维数组通常用于表示表格数据、坐标矩阵等。

let matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];

// 访问第二行，第三列的元素（值为 6）
console.log(matrix[1][2]); // 6

// 遍历二维数组
for (let i = 0; i < matrix.length; i++) {
    for (let j = 0; j < matrix[i].length; j++) {
        console.log(matrix[i][j]);
    }
}

掌握数组的特性及其常用方法，对于日常的数据处理至关重要。
