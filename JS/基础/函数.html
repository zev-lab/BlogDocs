JavaScript 基础：函数详解

函数是一段可以被重复调用的代码块，它用于封装特定的逻辑任务。函数使得代码模块化、减少了冗余，是 JavaScript 中最为重要的核心概念之一。

1. 声明与调用

在 JavaScript 中，函数不会在脚本加载时自动执行，而是需要通过调用或触发机制来执行。

声明函数 (Function Declaration)

使用 function 关键字：

function sayHello() {
    console.log("Hello World!");
}

// 主动调用
sayHello();

函数表达式 (Function Expression)

将一个匿名函数赋值给一个变量：

const greet = function() {
    console.log("Greetings!");
};

greet();

2. 参数与返回值

函数可以接收输入（参数），并可以产生输出（返回值）。

形参与实参

  • 形参 (形式参数)：声明函数时定义的变量，用于占位。
  • 实参 (实际参数)：调用函数时传入的具体数值。
// x, y 为形参
function add(x, y) {
    return x + y; // return 语句返回结果，并结束该函数的执行
}

// 10, 20 为实参
let sum = add(10, 20); 
console.log(sum); // 30

注意：return 相当于循环中的 break，它会立即终止函数的执行，return 后面的代码永远不会执行。

3. 匿名函数与自调用函数 (IIFE)

没有名字的函数叫匿名函数。匿名函数不能单独作为一行代码存在，通常作为回调函数或者封装作用域的自调用函数（IIFE）使用。

// 立即执行函数表达式 (IIFE)
// 这种模式常用于创建一个独立的作用域，避免变量污染全局环境
(function() {
    let privateVar = "我是局部的，外面访问不到";
    console.log("自调用函数执行：", privateVar);
})();

4. 闭包 (Closure)

闭包是 JavaScript 中非常重要且强大的特性。简单来说，闭包是指有权访问另一个函数作用域中的变量的函数。

通常在函数内部定义一个函数，并且内部函数访问了外部函数的局部变量，当内部函数被返回并在外部调用时，就形成了闭包。

闭包的应用场景：数据私有化与状态保存

function createCounter() {
    let count = 0; // 外部函数的局部变量
    
    // 返回的内部函数引用了 count，形成闭包
    return function() {
        count++;
        console.log("当前计数：", count);
    }
}

const myCounter = createCounter();
myCounter(); // 1
myCounter(); // 2
// count 变量驻留在内存中，没有被销毁，实现了数据的持久化和私有化保护。

警告：闭包会导致变量常驻内存，滥用闭包容易造成内存泄漏。

5. 定时器 (Timers)

JavaScript 提供了在一定时间后执行函数的机制，常需要用到回调函数。

setTimeout (一次性定时器)

在指定时间（毫秒）后，执行一次代码。

// 3秒后打印
let timerId = setTimeout(function() {
    console.log("3秒时间到了！");
}, 3000);

// 如果需要，可以提前取消
// clearTimeout(timerId);

setInterval (循环定时器)

每隔指定时间（毫秒），循环执行代码。

let num = 0;
let intervalId = setInterval(function() {
    num++;
    console.log(num);
    if (num >= 5) {
        clearInterval(intervalId); // 清除定时器
        console.log("停止计时");
    }
}, 1000); // 每 1000 毫秒(1秒)执行一次

6. 递归函数 (Recursion)

递归是指函数在内部调用自身的编程技巧。它主要用于解决具有重复且相似规律的问题，如树形结构遍历、阶乘等。

使用递归时，必须要有明确的终止条件，否则会导致死循环，最终造成栈溢出 (Stack Overflow)。

// 计算阶乘 (n!)
function factorial(n) {
    if (n === 1) { // 终止条件
        return 1;
    }
    return n * factorial(n - 1); // 调用自身
}

console.log(factorial(5)); // 5*4*3*2*1 = 120

总结

掌握函数的作用域、参数传递、返回值以及闭包、递归等高级用法，是构建健壮且可维护的 JavaScript 应用的基础。
