# JavaScript 基础：事件对象与事件机制

在前端开发中，用户与网页的交互（如点击按钮、滑动滚轮、按下键盘）都会触发**事件**。了解事件对象及事件流的机制，是编写高质量交互代码的关键。

## 1. 事件对象 (Event Object)

当事件发生时，浏览器会自动创建一个包含该事件所有相关信息的对象，并将其作为参数传递给事件处理函数，这个对象就是**事件对象**。

```javascript
document.querySelector('button').onclick = function(event) {
    // 兼容 IE8 及以下浏览器的写法
    var e = event || window.event;
    
    // 获取事件类型
    console.log(e.type); // "click"
    
    // 获取触发事件的具体目标元素
    // IE8 兼容写法： e.target || e.srcElement
    console.log(e.target); 
};
```

### 常见事件对象的属性
- **鼠标位置**：
  - `clientX / clientY`: 鼠标相对于**浏览器视口**的坐标。
  - `pageX / pageY`: 鼠标相对于**整个文档**的坐标。
  - `screenX / screenY`: 鼠标相对于**电脑屏幕**的坐标。
- **键盘按键**：
  - `keyCode`: 返回按下按键的数字编码。

## 2. 阻止默认行为

很多 HTML 标签具有默认行为（如 `<a>` 标签点击会跳转，`<form>` 标签点击提交会刷新页面）。如果不需要这些默认行为，可以通过事件对象进行阻止。

```javascript
document.querySelector('a').onclick = function(e) {
    var ev = e || window.event;
    
    // 现代浏览器阻止默认行为
    if (ev.preventDefault) {
        ev.preventDefault();
    } else {
        // IE 低版本阻止默认行为
        ev.returnValue = false;
    }
    
    // 在 on 绑定的事件中也可以直接 return false
    // return false;
};
```

## 3. 事件流（事件冒泡与事件捕获）

事件流描述的是页面接收事件的顺序。DOM2 级事件规定事件流分为三个阶段：**事件捕获阶段**、**处于目标阶段**、**事件冒泡阶段**。

- **事件捕获 (Event Capturing)**: 事件从最顶层的父节点（document）逐级向下传递，直到到达具体的目标节点。
- **事件冒泡 (Event Bubbling)**: 事件从目标节点开始，逐级向上向父节点传递。**通常我们的事件都是在冒泡阶段被处理的。**

### 阻止事件冒泡
在某些业务场景下（例如点击模态框的内容区不希望触发模态框背景的关闭事件），我们需要阻止事件冒泡。

```javascript
document.querySelector('.content').onclick = function(e) {
    var ev = e || window.event;
    
    // 现代浏览器阻止冒泡
    if (ev.stopPropagation) {
        ev.stopPropagation();
    } else {
        // IE 低版本阻止冒泡
        ev.cancelBubble = true;
    }
};
```

## 4. 事件绑定与事件监听

### DOM0 级事件绑定
使用 `on` + 事件名 的方式。缺点是同一元素的同一事件只能绑定一个处理函数，后面的会覆盖前面的。

```javascript
var btn = document.getElementById('btn');
btn.onclick = function() { console.log("第一次绑定"); };
btn.onclick = function() { console.log("第二次绑定，会覆盖上一个"); };
```

### DOM2 级事件监听 (addEventListener)
可以为同一个元素绑定多个相同的事件，并且可以选择是在捕获阶段还是冒泡阶段执行。

```javascript
var btn = document.getElementById('btn');

// 参数1: 事件名(不带on)
// 参数2: 事件处理函数
// 参数3: 布尔值。false 表示在冒泡阶段执行(默认)，true 表示在捕获阶段执行
btn.addEventListener('click', function() {
    console.log("监听器 1");
}, false);

btn.addEventListener('click', function() {
    console.log("监听器 2，不会被覆盖");
}, false);
```

## 5. 事件委托 (Event Delegation)

当我们需要为大量同级别的子元素（例如一个很长的 `<ul>` 列表里的每一个 `<li>`）绑定事件时，如果逐个绑定会非常消耗内存，并且对于动态添加的节点也无法直接生效。

**事件委托**利用了**事件冒泡**的原理，将子元素的事件统一绑定在它们的父元素上。

```javascript
var ul = document.querySelector('ul');

ul.addEventListener('click', function(e) {
    // 无论点击哪个 li，事件最终都会冒泡到 ul 上
    // 通过 e.target 可以获知用户实际点击的是哪一个具体的节点
    if (e.target.tagName.toLowerCase() === 'li') {
        console.log("你点击了列表项：", e.target.innerHTML);
    }
});
```

通过事件委托，不仅极大地优化了性能，也使得动态添加到 `ul` 中的 `li` 元素天然拥有了点击事件。
