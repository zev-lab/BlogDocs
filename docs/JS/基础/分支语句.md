# JavaScript 基础：分支语句与条件判断

在 JavaScript 编程中，代码通常是从上往下顺序执行的。但为了应对复杂的业务逻辑，我们需要程序能够根据不同的条件，选择执行不同的代码块。这就是**分支语句（条件判断语句）**的作用。

## 1. 逻辑运算符与关系运算符

在深入分支语句之前，我们必须先了解条件表达式中最为常用的逻辑和关系运算符，它们的返回值通常都是布尔值（`true` 或 `false`）。

### 关系运算符
用于比较两侧的操作数：
- `>`, `<`, `>=`, `<=`：大于，小于，大于等于，小于等于。
- `==` 与 `!=`：值相等 / 值不相等（会进行隐式类型转换）。
- `===` 与 `!==`：全等 / 不全等（**推荐使用**，不仅比较值，还比较数据类型，不会发生隐式转换）。

```javascript
console.log(3 > 5);       // false
console.log(3 == '3');    // true (发生隐式转换)
console.log(3 === '3');   // false (类型不同，一个是数字，一个是字符串)
```

### 逻辑运算符
用于组合多个关系表达式：
- `&&` (逻辑与)：当两侧条件**都**成立时，结果为 true；否则为 false。
- `||` (逻辑或)：当两侧条件**至少有一个**成立时，结果为 true；否则为 false。
- `!` (逻辑非)：取反。真变假，假变真。

**短路运算特性**：
在 JavaScript 中，逻辑运算存在“短路”特性。
- `A && B`：如果 A 为假，则直接返回 A，不再计算 B；只有 A 为真时才计算并返回 B。
- `A || B`：如果 A 为真，则直接返回 A，不再计算 B；只有 A 为假时才计算并返回 B。

*注意：以下值在逻辑判断中会被自动转换为 `false`：`0`, `""` (空字符串), `null`, `undefined`, `NaN`。*

## 2. if 语句

这是最基本的条件判断语句。如果括号内的条件表达式为真，则执行大括号内的代码。

```javascript
let score = 85;

if (score >= 60) {
  console.log("恭喜你，及格了！");
}
```

## 3. if...else 语句

在条件不成立时，我们可以使用 `else` 来执行备用的代码块。

```javascript
let isVip = false;

if (isVip) {
  console.log("欢迎尊贵的 VIP 用户！");
} else {
  console.log("欢迎普通用户，充值体验更多特权。");
}
```

## 4. 多重 if...else if...else

当有多个互斥条件需要判断时，可以使用 `else if` 链。程序会自上而下匹配条件，一旦有条件满足，执行对应的代码块后，整个分支语句就会结束，后面的条件将不再判断。

```javascript
let color = "red";

if (color === "red") {
  console.log("停下！");
} else if (color === "yellow") {
  console.log("准备！");
} else if (color === "green") {
  console.log("通行！");
} else {
  console.log("交通灯故障！");
}
```

## 5. switch 语句

当针对同一个变量进行多个严格相等的定值匹配时，`switch` 语句是比 `if...else if` 更清晰、执行效率也略高的选择。

```javascript
let day = 3;

switch (day) {
  case 1:
    console.log("星期一");
    break;
  case 2:
    console.log("星期二");
    break;
  case 3:
    console.log("星期三");
    break; // 必须使用 break 跳出 switch 语句，否则会发生“穿透”现象
  default:
    // 如果上面都没有匹配项，则执行 default
    console.log("未知的日期");
    break;
}
```
**注意**：`switch` 的比较使用的是严格等于（`===`），且每个 `case` 执行完毕后一定要加上 `break`，除非你有意利用穿透（fall-through）特性执行多个连续的逻辑。

## 6. 三元运算符 (Ternary Operator)

对于简单的 if...else 判断并赋值，可以使用三元运算符，语法更加简洁。
语法：`条件表达式 ? 成立时的值 : 不成立时的值`

```javascript
let age = 20;

// 使用 if...else
let identity;
if (age >= 18) {
  identity = "成年人";
} else {
  identity = "未成年人";
}

// 使用三元运算符，等效且简洁
let status = age >= 18 ? "成年人" : "未成年人";
console.log(status); // 成年人
```

## 总结

- 对于范围判断（如 `score > 90`），使用 `if...else if`。
- 对于单一变量的具体固定值判断，使用 `switch` 使得代码更加清晰。
- 对于简单的非此即彼的赋值，优先使用三元运算符。
