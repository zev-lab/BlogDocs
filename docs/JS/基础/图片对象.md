# JavaScript 基础：图片对象与懒加载

在前端开发中，图片（Image）是非常常见且占用带宽最大的资源之一。JavaScript 提供了原生的 `Image` 对象，我们可以借此实现图片的预加载和懒加载等性能优化技术。

## 1. 动态创建图片对象

除了在 HTML 中直接书写 `<img src="...">` 标签，我们还可以通过 JavaScript 动态创建图片对象。

```javascript
// 创建一个新的图片元素对象
let img = new Image();

// 赋值 src 属性。只要赋值了 src，浏览器就会立刻在后台发起网络请求下载该图片
img.src = 'https://example.com/demo.png';

// 将图片元素插入到页面中
document.body.appendChild(img);
```

## 2. 监听图片的加载状态

图片的加载是一个**异步过程**。在图片尚未完全加载完毕之前，尝试去获取它的真实宽高（naturalWidth）通常会得到 0。我们需要利用 `onload` 和 `onerror` 事件。

```javascript
let img = new Image();
img.src = 'https://example.com/demo.png';

// 当图片资源完全加载完毕后触发
img.onload = function() {
    console.log("图片加载成功！");
    console.log("图片的真实宽度为: ", img.width); // 此时才能准确获取宽度
};

// 当图片资源加载失败（如 404）时触发
img.onerror = function() {
    console.error("图片加载失败！显示默认占位图");
    img.src = 'default-placeholder.png'; // 错误容错处理
};
```

## 3. 图片预加载 (Preloading)

当页面拥有大量高清大图，或者是一个依赖连续动画帧（通过切换图片实现）的 H5 活动页时，如果边看边加载，用户体验会极差。此时我们需要**图片预加载**：即在后台默默加载这些图片，等全部加载完毕后再展示页面或开始动画。

```javascript
let imgUrls = [
    'img/1.png',
    'img/2.png',
    'img/3.png'
];
let loadedCount = 0;

imgUrls.forEach(url => {
    let img = new Image();
    img.onload = () => {
        loadedCount++;
        let progress = Math.floor((loadedCount / imgUrls.length) * 100);
        console.log(`当前加载进度：${progress}%`);
        
        if (loadedCount === imgUrls.length) {
            console.log("所有图片已加载完毕，可以开始渲染页面！");
        }
    };
    img.src = url;
});
```

## 4. 图片懒加载 (Lazy Loading)

对于长列表页面（如电商商品流、图片社交网站），如果一次性加载几百张图片，会导致页面渲染严重卡顿，并浪费极大的带宽资源。
**图片懒加载**（延时加载）的核心思想是：**只加载当前浏览器可视区域内的图片，当用户向下滚动，图片即将出现在视野内时，再去请求真实图片资源。**

### 实现原理
1. 将真实的图片地址存在自定义属性 `data-src`（或 `msrc`）中。
2. 初始的 `src` 放置一张非常小的占位图或 Loading 图，甚至为空。
3. 监听页面的滚动事件 `onscroll`，计算图片元素的位置是否进入了可视区域。
4. 如果进入，则将 `data-src` 的值取出来赋给真实的 `src` 属性触发加载。

```html
<!-- HTML 结构 -->
<img src="loading.gif" data-src="real-image.jpg" class="lazyload" />
<img src="loading.gif" data-src="real-image2.jpg" class="lazyload" />
```

```javascript
// JS 实现图片懒加载
window.onload = function() {
    let imgs = document.querySelectorAll('.lazyload');

    function lazyLoad() {
        // 获取浏览器可视窗口高度
        let viewHeight = document.documentElement.clientHeight;
        // 获取页面垂直滚动的距离
        let scrollTop = document.documentElement.scrollTop || document.body.scrollTop;
        
        for (let i = 0; i < imgs.length; i++) {
            let img = imgs[i];
            
            // 如果图片还未被加载且进入了可视区域
            // img.offsetTop 是元素距离文档顶部的距离
            if (img.getAttribute('data-src') && (img.offsetTop < viewHeight + scrollTop)) {
                // 将真实地址赋给 src
                img.src = img.getAttribute('data-src');
                // 移除 data-src 属性，防止重复加载
                img.removeAttribute('data-src');
            }
        }
    }

    // 初始执行一次
    lazyLoad();

    // 监听滚动事件（实际开发中，建议配合节流防抖函数(throttle)来优化性能）
    window.onscroll = lazyLoad;
};
```
*提示：现代浏览器已经原生支持了 `loading="lazy"` 属性，对于不需要兼容老旧浏览器的场景，直接在 HTML 标签上写 `<img src="..." loading="lazy">` 即可实现原生懒加载。*
