# JavaScript 基础：循环语句详解

在编程中，遇到需要重复执行多次相同或相似规律的代码时，如果单纯依靠复制粘贴，不仅代码冗长，而且极难维护。此时，我们就需要使用**循环结构**。

JavaScript 提供了多种循环语句来处理不同场景的重复逻辑。

## 1. for 循环

`for` 循环是最常用的一种循环，尤其适用于**已知循环次数**的场景。

### 语法
```javascript
for (初始化表达式; 条件表达式; 迭代更新表达式) {
    // 循环体代码
}
```
- **初始化表达式**：在循环开始前执行一次，通常用于声明和初始化循环变量（如 `let i = 0`）。
- **条件表达式**：在每次执行循环体之前都会进行判断。如果为 `true`，则执行循环体；如果为 `false`，则立即结束整个循环。
- **迭代更新表达式**：在每次循环体执行完毕后执行，通常用于更新循环变量的值（如 `i++`）。

### 示例
```javascript
// 在控制台输出 5 次 Hello World
for (let i = 0; i < 5; i++) {
    console.log("Hello World, 当前次数: " + i);
}

// 计算 1 到 100 的累加和
let sum = 0;
for (let i = 1; i <= 100; i++) {
    sum += i;
}
console.log("1 到 100 的和是：" + sum);
```

## 2. while 循环

`while` 循环更适合处理**循环次数未知，只知道终止条件**的场景。只要条件为真，循环体就会一直执行下去。

### 语法
```javascript
while (条件表达式) {
    // 循环体代码
    // 注意：务必在循环体内包含能改变条件表达式结果的代码，否则会造成死循环！
}
```

### 示例
```javascript
// 输出 1 到 5
let n = 1;
while (n <= 5) {
    console.log(n);
    n++; // 如果没有这一句，n 永远为 1，循环永远不会停止
}
```

## 3. do...while 循环

`do...while` 循环与 `while` 的核心区别在于：它先不管条件是否成立，**无论如何都会先执行一次循环体**，然后再判断条件是否成立来决定是否继续下一次循环。

### 语法
```javascript
do {
    // 循环体代码
} while (条件表达式);
```

### 示例
```javascript
let x = 10;
do {
    console.log("这行代码至少会被打印一次！当前值：" + x);
    x++;
} while (x < 5); // 即使一开始就不满足条件，上面也依然执行了一次
```

## 4. 循环控制：break 与 continue

在循环执行的过程中，我们可以人为干预它的走向。

- **`break`**: 立即**彻底结束**当前整个循环。跳出循环体，继续执行循环外后面的代码。
- **`continue`**: 立即停止执行**本次**循环体内剩余的代码，直接**跳跃进入下一次**循环的条件判断和执行。

```javascript
for (let i = 1; i <= 10; i++) {
    if (i === 5) {
        break; // 当 i 等于 5 时，彻底停止循环，所以只会输出 1,2,3,4
    }
    console.log("break 测试: " + i);
}

for (let j = 1; j <= 5; j++) {
    if (j === 3) {
        continue; // 当 j 等于 3 时，跳过当次循环后面的输出语句。输出 1,2,4,5
    }
    console.log("continue 测试: " + j);
}
```

## 5. for...in 循环

`for...in` 语句用于**遍历对象的所有可枚举属性**（包括继承的属性）。在循环遍历数组时，虽然也可以使用 `for...in`（遍历出的是数组的索引），但强烈建议**只用它遍历普通对象**。

```javascript
let person = {
    name: "Alice",
    age: 25,
    city: "Beijing"
};

for (let key in person) {
    // key 为属性名
    // 必须通过 obj[key] 这种形式来获取属性值，不能使用 obj.key
    console.log("属性：" + key + ", 值为：" + person[key]);
}
```

## 6. 循环的嵌套

循环内部可以再包一层循环，这就是嵌套循环。**外层循环每执行一次，内层循环会完整地执行一遍所有的轮次。**

常用于生成二维表格、打印各种图形等。

```javascript
// 打印九九乘法表
for (let i = 1; i <= 9; i++) {       // 控制行数
    let rowContent = "";
    for (let j = 1; j <= i; j++) {   // 控制每一行里的列数
        rowContent += `${j}*${i}=${i*j}\t`;
    }
    console.log(rowContent);         // 打印出完整的每一行
}
```
掌握好各种循环结构及其终止条件，能极大提升我们处理批量重复数据时的效率，是编程基本功中至关重要的一环。
