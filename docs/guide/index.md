# 欢迎来到前端学习指南 🚀

欢迎来到本技术博客！这里汇集了关于前端开发、图形渲染（Three.js）、跨端开发（Flutter、UniApp）以及各种常用工具的实战指南和经验总结。

## 📚 内容导航

我们致力于提供高质量、易于理解的实战技术文章。你可以通过左侧导航栏浏览相关主题，以下是核心板块：

- **[JavaScript 奇妙之旅](./start.md)**: 从基础到实战，带你用原生 JS 开发经典小游戏（五子棋、贪吃蛇、植物大战僵尸等），深入理解 DOM 和 Canvas 渲染。
- **Three.js 3D 渲染**: 探讨 WebGL 的魅力。从基础的[模型加载](../THREE/模型加载.md)到复杂的空间交互[射线检测](../THREE/射线检测.md)，帮你构建 Web 3D 互动体验。
- **Flutter 跨端实战**: 学习 Google 高性能跨端框架。从[第一天的基础概念](../flutter/flutter第一天.md)开始，掌握 Widget 树和状态管理。

### 💼 项目经验选录

**1. 在线能耗环保监测平台 (Vue 生态)**
此项目为一套企业级能耗在线监测平台，采用 Vue 框架搭建，包含电水汽能源管理、报表管理等模块，支持多端登录及完善的权限控制。
- 采用 Vue + Element-UI + Vuex + Axios + 百度地图 技术栈。
- 封装自定义复杂组件，实现细粒度的按钮级权限管理。
- 大量应用防抖/节流及渲染优化手段，成功提升了系统的流畅度。解决百度地图离线加载等难点。

**2. 环境在线监测平台 (大屏可视化)**
利用 Vue 生态配合 ECharts 结合 3D 图表，实现“环保一张图”、大气、水污染监测等模块，并包含工业组态流程图展示。

**3. 安全预测分析与风险评估系统**
基于 Vue 研发的通用型风险预测分析平台，通过 Vue 的数据驱动特性解决了复杂的动态表单技术难点，实现了高效的接口联调与页面渲染。

**4. 走你洗车 (UniApp 小程序)**
全自动洗车机无人值守小程序终端，支持微信扫码洗车、附近站点查看。
- 使用 UniApp + uView-UI 快速开发。
- 实现 Canvas 分享海报生成、长列表瀑布流渲染及懒加载。
- 结合地图 SDK 进行定位、打点并展示相关的监控视频信息。
