### 1、HTML 面试题

#### 1.1 如何理解 HTML 语义化？

- 让人更容易读懂（增加代码可读性）。
- 让搜索引擎更容易读懂，有助于爬虫抓取更多的有效信息，爬虫依赖于标签来确定上下文和各个关键字的权重（SEO）。
- 在没有 CSS 样式下，页面也能呈现出很好地内容结构、代码结构。

#### 1.2 从浏览器地址栏输入 URL 到请求返回发生了什么

> URL（Uniform Resource Locator），统一资源定位符，用于定位互联网上资源，俗称网址。

1. 输入 URL 后解析出协议、主机、端口、路径等信息，并构造一个 HTTP 请求。
2. 浏览器检查缓存（强缓存、协商缓存）。
3. DNS解析：将域名解析为 IP 地址。
4. 建立 TCP 连接（三次握手）。
5. 发送 HTTP 请求。
6. 服务器处理请求并返回 HTTP 报文。
7. 浏览器渲染页面（解析 HTML 构建 DOM 树，解析 CSS 构建 CSSOM 树，结合生成 Render 树，计算布局，绘制页面）。
8. 断开 TCP 连接（四次挥手）。

### 2、CSS 面试题

#### 2.1 盒模型介绍

CSS 中的盒模型有以下两种：**标准盒模型**、**IE（替代）盒模型**。

两种盒子模型都是由 `content + padding + border + margin` 构成，其大小都是由 `content + padding + border` 决定的，但是盒子内容宽/高度（即 `width/height`）的计算范围根据盒模型的不同会有所不同：

- **标准盒模型**：只包含 `content` 。
- **IE（替代）盒模型**：`content + padding + border` 。

可以通过 `box-sizing` 来改变元素的盒模型：

- `box-sizing: content-box` ：标准盒模型（默认值）。
- `box-sizing: border-box` ：IE（替代）盒模型/怪异盒模型。

#### 2.2 对 BFC 的理解

BFC 即**块级格式化上下文** (Block Formatting Context)。根据盒模型可知，每个元素都被定义为一个矩形盒子，然后盒子的布局会受到尺寸、定位、盒子的子元素或兄弟元素、视口尺寸等因素影响。BFC 用于决定块级盒的布局及浮动相互影响范围的一个区域。

**BFC 有一些特性:**
1. 块级元素会在垂直方向一个接一个排列。
2. 在 BFC 中上下相邻的两个容器的 `margin` 会重叠，创建新的 BFC 可以避免外边距重叠。
3. 计算 BFC 的高度时，需要计算浮动元素的高度（清除浮动）。
4. BFC 区域不会与浮动元素发生重叠（常用于两栏自适应布局）。
5. BFC 是独立的容器，容器内部元素不会影响外部元素。

**创建 BFC 的方式：**
- 根元素（`<html>`）
- 浮动元素（`float` 不为 `none`）
- 绝对定位元素（`position` 为 `absolute` 或 `fixed`）
- `overflow` 的值不为 `visible` 的元素（如 `hidden`, `auto`, `scroll`）
- 弹性元素（`display` 为 `flex` 或 `inline-flex`）
- 网格元素（`display` 为 `grid`）
- `display` 为 `inline-block`, `table-cell`, `table-caption`

#### 2.3 Flex 布局

Flex 布局（Flexible Box）是 CSS3 引入的一种一维布局模型，提供了更加高效的方式来对齐、分布空间以及响应式地布局元素，即使未知它们的大小。

**容器属性（父元素）：**
- `flex-direction`: 决定主轴的方向（`row`, `row-reverse`, `column`, `column-reverse`）。
- `flex-wrap`: 决定是否换行（`nowrap`, `wrap`, `wrap-reverse`）。
- `flex-flow`: `flex-direction` 和 `flex-wrap` 的简写。
- `justify-content`: 定义项目在主轴上的对齐方式（`flex-start`, `flex-end`, `center`, `space-between`, `space-around`, `space-evenly`）。
- `align-items`: 定义项目在交叉轴上如何对齐（`flex-start`, `flex-end`, `center`, `baseline`, `stretch`）。
- `align-content`: 定义多根轴线的对齐方式。

**项目属性（子元素）：**
- `order`: 定义项目的排列顺序，数值越小越靠前，默认为 0。
- `flex-grow`: 定义项目的放大比例，默认为 0（即如果存在剩余空间，也不放大）。
- `flex-shrink`: 定义项目的缩小比例，默认为 1（即如果空间不足，该项目将缩小）。
- `flex-basis`: 定义了在分配多余空间之前，项目占据的主轴空间（类似 width）。
- `flex`: `flex-grow`, `flex-shrink` 和 `flex-basis` 的简写，默认值为 `0 1 auto`。
- `align-self`: 允许单个项目有与其他项目不一样的对齐方式，可覆盖 `align-items` 属性。

## 三、JavaScript 基础与进阶

### 3.1 闭包 (Closure)
**闭包**是指有权访问另一个函数作用域中的变量的函数。通常在函数嵌套中产生。
- **优点**：可以读取函数内部的变量；让这些变量的值始终保持在内存中，不被垃圾回收机制回收。
- **缺点**：过度使用闭包会导致内存消耗过大，甚至导致内存泄漏。

### 3.2 原型与原型链
每个 JavaScript 对象（除 `null` 外）在创建的时候就会与之关联另一个对象，这个对象就是我们所说的原型（`prototype`）。当试图访问一个对象的属性时，如果没有找到，就会去找该对象的原型，直到找到最顶层的 `Object.prototype`。这就是**原型链**。

### 3.3 Promise 及其原理
Promise 是异步编程的一种解决方案，比传统的解决方案（回调函数和事件）更合理、更强大。
- **三种状态**：Pending（进行中）、Resolved（已完成）、Rejected（已失败）。
- 状态一旦改变就不会再变。
- **常用方法**：`then`, `catch`, `finally`, `Promise.all`, `Promise.race`。
