Three.js 射线检测 (Raycaster) 与对象交互

在浏览器中浏览 3D 图形时，用户通常希望与 3D 场景进行交互，比如鼠标点击选中某个模型、悬停高亮等。Three.js 提供了 Raycaster（射线投射器）来实现这种 3D 空间的碰撞检测和拾取（Picking）。

本文将详细讲解如何使用 Raycaster，以及在画布（Canvas）未占满全屏时常见的拾取坐标偏差问题及其解决方案。

1. 射线投射原理解析

射线检测的原理是：从摄像机（Camera）的中心点，经过鼠标在屏幕上的 2D 坐标（转换为标准化设备坐标 NDC），向 3D 场景发射一条无限长的“射线”。计算这条射线穿过了场景中的哪些三维物体。穿过的所有物体即为被鼠标“点中”的对象。

2. 基础拾取实现 (全屏 Canvas)

当你的 Three.js Canvas 占据整个浏览器视口（window.innerWidth 和 window.innerHeight）时，计算坐标相对简单。

import * as THREE from 'three';

// 声明 raycaster 和 mouse 变量
const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();

/**
 * 获取点击到的模型
 * @param {Event} event 鼠标事件对象
 * @param {THREE.Scene} scene 场景对象
 * @param {THREE.Camera} camera 摄像机对象
 */
function getIntersects(event, scene, camera) {
    // 1. 计算鼠标的标准化设备坐标 (NDC)
    // 范围是 -1 到 +1
    mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
    mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;

    // 2. 通过摄像机和鼠标位置更新射线
    raycaster.setFromCamera(mouse, camera);

    // 3. 计算射线和场景中所有对象的交点
    // 第二个参数 true 表示是否检查所有后代（递归检查）
    const intersects = raycaster.intersectObjects(scene.children, true);

    return intersects;
}

// 绑定点击事件
window.addEventListener('click', (event) => {
    const intersects = getIntersects(event, scene, camera);
    
    if (intersects.length > 0) {
        // intersects[0] 是距离摄像机最近的被点击对象
        console.log('点击到了物体:', intersects[0].object.name);
        
        // 比如将点击的物体变成红色
        intersects[0].object.material.color.set(0xff0000);
    }
}, false);

返回的 intersects 是一个数组，按照距离相机的远近排序。数组中的每个元素包含以下有用信息：

  • object: 射线击中的 THREE.Object3D。
  • distance: 射线起点到交叉点的距离。
  • point: 交叉点的 3D 坐标 (THREE.Vector3)。
  • face: 击中的几何体面。

3. 常见问题：局部容器中的坐标偏差

[!WARNING] 踩坑预警：很多项目的三维渲染区是嵌在某个 DIV 容器中的，而不是占据全屏（例如侧边栏占用了一部分宽度，或者上方有导航栏）。此时如果依然使用 window.innerWidth 和 event.clientX 来计算坐标，将会导致严重的“点不准”问题，鼠标点在模型上却什么都选不中。

解决方案：必须基于 Canvas 所在的 DOM 元素的实际尺寸和相对屏幕的位置（getBoundingClientRect）来计算标准化坐标。

局部画布的准确坐标计算：

/**
 * 局部容器的射线拾取
 * @param {Event} event 鼠标事件
 * @param {THREE.Scene} scene 场景
 * @param {THREE.Camera} camera 摄像机
 * @param {HTMLElement} canvas 渲染用的 dom 元素
 */
function getCanvasIntersects(event, scene, camera, canvas) {
    // 获取元素的大小及其相对于视口的位置
    const rect = canvas.getBoundingClientRect();
    
    // 计算鼠标相对于画布的局部坐标
    const localX = event.clientX - rect.left;
    const localY = event.clientY - rect.top;

    // 将局部坐标转为标准化设备坐标 (NDC)，范围 [-1, 1]
    const x = (localX / canvas.clientWidth) * 2 - 1;
    const y = -(localY / canvas.clientHeight) * 2 + 1; 

    // 使用 Vector2 存储坐标
    const mouse = new THREE.Vector2(x, y);

    // 设置射线
    const raycaster = new THREE.Raycaster();
    raycaster.setFromCamera(mouse, camera);

    // 返回选中对象
    return raycaster.intersectObjects(scene.children, true);
}

// 示例调用
const myCanvas = document.getElementById('webgl-output');
myCanvas.addEventListener('click', (e) => {
    const intersects = getCanvasIntersects(e, scene, camera, myCanvas);
    if (intersects.length > 0) {
        console.log('局部画布准确拾取成功！');
    }
});

[!TIP] 性能优化建议：intersectObjects(scene.children, true) 每次都会遍历场景中的所有物体并计算几何交点，当场景复杂时会非常消耗性能。建议的做法是：将可以被点击的物体放入一个单独的数组中（例如 clickableObjects），然后只对这个数组进行检测：raycaster.intersectObjects(clickableObjects, false)。

4. 进阶：射线拾取在触摸屏上的应用

在移动端，我们需要监听 touchstart 事件而不是 click，并且取 event.touches[0] 里的坐标。

canvas.addEventListener('touchstart', (event) => {
    // 阻止默认滚动行为
    event.preventDefault(); 
    
    if (event.touches.length > 0) {
        // 将 event.touches[0] 作为事件源传入上面的拾取函数
        const touch = event.touches[0];
        const intersects = getCanvasIntersects(touch, scene, camera, canvas);
        // ...处理业务逻辑
    }
}, { passive: false });

总结

  1. Three.js 中的 3D 交互主要依赖 Raycaster 射线投射。
  2. 核心是将鼠标点击的 2D 坐标转换成范围在 [-1, 1] 的 NDC 坐标。
  3. 当 Canvas 不是全屏时，务必使用 getBoundingClientRect() 计算出相对偏移，以防止拾取错位。
  4. 为了性能，应尽量减少参与射线计算的网格（Mesh）数量。
