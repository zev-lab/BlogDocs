Three.js 模型加载指南

在实际的三维项目开发中，直接使用 Three.js 的 API 拼接复杂的几何体是非常困难的。通常的做法是由设计师在专门的三维建模软件（如 Blender、C4D、3d Max、Maya 等）中制作模型，然后导出为特定的格式，最后通过 Three.js 提供的各种 Loader 加载到场景中。

本文将详细介绍如何在 Three.js 中加载常见的 3D 模型格式，特别是目前最主流的 GLTF/GLB 格式，以及如何处理材质、动画和性能优化。

1. 常见模型格式

在 Three.js 中，支持多种 3D 模型格式。以下是几种最常见的：

  • GLTF / GLB: 被称为“3D界的JPEG”，是目前 WebGL 开发的首选格式。它支持几何体、材质、动画、骨骼等，并且体积小，加载快。
  • OBJ: 一种简单的 3D 模型格式，通常只包含几何体数据（顶点、法线、UV），如果需要材质，必须配合 .mtl 文件。不支持动画。
  • FBX: 包含丰富的模型信息，支持动画。通常体积较大，加载比 GLTF 慢。

[!TIP] 最佳实践：在 Web 开发中，尽可能使用 GLTF 或 GLB 格式。如果设计师提供的是 FBX 或 OBJ，可以利用 Blender 工具将其转换为 GLTF。

2. 加载 GLTF 模型 (GLTFLoader)

Three.js 核心库并不包含模型加载器。你需要从 three/examples/jsm/loaders 中引入对应的加载器。

2.1 引入加载器

import * as THREE from 'three';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';

2.2 基础加载代码

使用 GLTFLoader 的基本步骤如下：

// 初始化场景、相机和渲染器...
const scene = new THREE.Scene();

// 实例化加载器
const loader = new GLTFLoader();

// 可选：显示加载进度
const onProgress = (xhr) => {
    if (xhr.lengthComputable) {
        const percentComplete = (xhr.loaded / xhr.total) * 100;
        console.log(`模型加载进度: ${Math.round(percentComplete, 2)}%`);
    }
};

// 错误处理函数
const onError = (error) => {
    console.error('模型加载失败:', error);
};

// 开始加载模型
loader.load(
    'models/my_model.glb', // 模型路径
    (gltf) => {
        const model = gltf.scene;
        
        // 调整模型大小和位置
        model.scale.set(1, 1, 1);
        model.position.set(0, 0, 0);
        
        // 将模型添加到场景中
        scene.add(model);
        
        console.log('模型加载成功!');
    },
    onProgress,
    onError
);

3. 处理模型动画

很多 GLTF 模型不仅包含静态的网格，还包含了动画数据。可以通过 THREE.AnimationMixer 来播放这些动画。

let mixer; // 声明为全局变量，因为需要在 render 循环中更新

loader.load('models/animated_model.glb', (gltf) => {
    const model = gltf.scene;
    scene.add(model);
    
    // 检查模型是否包含动画
    const animations = gltf.animations;
    if (animations && animations.length) {
        // 创建 AnimationMixer
        mixer = new THREE.AnimationMixer(model);
        
        // 播放第一个动画
        const action = mixer.clipAction(animations[0]);
        action.play();
    }
});

// 在你的渲染循环 (requestAnimationFrame) 中更新 mixer
const clock = new THREE.Clock();

function animate() {
    requestAnimationFrame(animate);
    
    const delta = clock.getDelta();
    if (mixer) {
        mixer.update(delta); // 推进动画时间
    }
    
    renderer.render(scene, camera);
}

4. 模型压缩与优化 (DRACOLoader)

为了减少模型文件的体积，通常会对模型进行 Draco 压缩。普通的 GLTFLoader 无法直接解析压缩后的模型，必须搭配 DRACOLoader 使用。

import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';
import { DRACOLoader } from 'three/examples/jsm/loaders/DRACOLoader.js';

const loader = new GLTFLoader();

// 初始化 DRACOLoader
const dracoLoader = new DRACOLoader();
// 设置 Draco 解码器路径，这些文件在 Three.js 包的 examples/jsm/libs/draco/ 目录下
dracoLoader.setDecoderPath('https://www.gstatic.com/draco/versioned/decoders/1.4.1/');
// 将 DRACOLoader 挂载到 GLTFLoader
loader.setDRACOLoader(dracoLoader);

// 之后就可以正常加载经过压缩的 GLB 文件了
loader.load('models/compressed_model.glb', (gltf) => {
    scene.add(gltf.scene);
});

[!WARNING] 解码 Draco 模型需要消耗一定的 CPU 资源。通常建议对体积较大的模型使用 Draco 压缩，而体积本来就很小的模型直接使用普通 GLB 即可。

5. 材质与环境光设置

有时候你会发现加载的模型“黑乎乎的一片”，这通常是因为场景中没有光照，或者是材质的属性需要环境贴图（Environment Map）才能正常显示。

PBR材质（GLTF默认使用）需要环境光或直接光照才能显现颜色。

// 添加环境光
const ambientLight = new THREE.AmbientLight(0xffffff, 0.5); // 白光，强度0.5
scene.add(ambientLight);

// 添加平行光 (模拟太阳光)
const directionalLight = new THREE.DirectionalLight(0xffffff, 1);
directionalLight.position.set(5, 10, 7);
scene.add(directionalLight);

如果是高反射材质（金属/粗糙度工作流），使用 HDRI 环境贴图效果最佳：

import { RGBELoader } from 'three/examples/jsm/loaders/RGBELoader.js';

new RGBELoader()
    .setPath('textures/equirectangular/')
    .load('royal_esplanade_1k.hdr', function (texture) {
        texture.mapping = THREE.EquirectangularReflectionMapping;

        scene.background = texture;
        scene.environment = texture; // 将其作为场景的环境贴图
    });

总结

  1. 优先使用 GLTF/GLB 格式。
  2. 使用 GLTFLoader 进行加载，包含动画的数据使用 AnimationMixer 驱动。
  3. 大型模型可以先进行 Draco 压缩，然后配合 DRACOLoader 进行加载。
  4. 模型看不见或颜色不对时，检查相机位置和场景光照设置。
